🚀 Amazon Sales Analysis Dashboard — Built in Power BI

I built a fully interactive Amazon Sales Analysis Dashboard to turn raw e-commerce data into real-time, actionable insights. Sharing a quick look at it in action! 🎥



📊 What it tracks:

 ✅ YTD Sales & QTD Sales

 ✅ YTD Quantity Sold & YTD Reviews

 ✅ Monthly & Weekly Sales Trends

 ✅ Sales by Product Category (YTD vs QTD comparison)

 ✅ Top 5 Products by Sales and by Customer Reviews



🎬 In the demo, you can see the dashboard responding live as I apply filters — Product Category, Year, and Quarter — and every KPI, chart, and table recalculates instantly. That's the real power of Power BI: slice the data any way you want, and the whole story updates in real time.



🛠️ Tools Used: Power BI | DAX | Power Query | Data Modeling | Interactive Visualization.



This project helped me sharpen:

 🔹 Building dynamic, filter-driven dashboards

 🔹 DAX measures for YTD/QTD calculations

 🔹 UI/UX design for data storytelling

 🔹 Translating raw sales data into decision-ready insights
